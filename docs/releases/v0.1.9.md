# Siliang Engine v0.1.9

This stability release covers prompt reuse in the server and two GGUF conversion cases.
It retains the v0.1.8 upstream base, llama.cpp `b11188`.

## Prompt cache recovery

When a hybrid or recurrent model rejects a partial rollback of a cached prompt,
the server clears the affected slot's state and checkpoints, logs the rejected
position, and processes the full prompt. A long request can therefore incur a
full prefill on recovery. When the rollback succeeds, the server reuses the
cached prefix.

## GGUF conversion

- The expert-major converter preserves the last tensor's payload through its
  final byte, including when the input ends without alignment padding.
- The GGUF reader and writer preserve the declared element type of an empty
  metadata array when that type is supplied explicitly.
